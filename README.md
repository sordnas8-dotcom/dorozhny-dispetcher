# Дорожный диспетчер — GitHub Pages

Бесплатная версия без серверной части и входа через ChatGPT.

Сохранены 40 подразделений, показатели и ОДХ, контакты, диаграмма, 5 разделов карт, быстрый просмотр PDF и раздельное переключение листов.

Включена 21 схема, добавленная при разработке. Еще 91 загруженный PDF находится в защищенном хранилище действующего сайта. Они не потеряны и не включены в стартовый архив; список — PENDING_SCHEMES.json. Для переноса используйте страницу экспорта действующего сайта, затем «Обновление данных → Перенос схем».

## Простая публикация без установки программ

1. Создайте бесплатный аккаунт GitHub и публичный репозиторий dorozhny-dispetcher.
2. Из папки PUBLISH этого архива загрузите файлы site-part-*.zip и папку tools в корень репозитория: Add file → Upload files → Commit changes. ZIP-части не распаковывайте: это данные для автоматической публикации.
3. В репозитории выберите Add file → Create new file. В качестве имени укажите .github/workflows/pages.yml. Скопируйте в него содержимое PUBLISH/pages.yml и сохраните через Commit changes.
4. Settings → Pages → Source → GitHub Actions.
5. Actions → Publish Pages → Run workflow. Когда выполнение станет зеленым, ссылка появится в Settings → Pages.
6. Проверьте эту ссылку без VPN. Доступность GitHub Pages и Google Maps зависит от сети посетителя и не гарантируется размещением.

На бесплатном тарифе репозиторий публичный. Содержимое справочника, включая опубликованные контакты и PDF, будет доступно посетителям и в файлах репозитория.

## Обновление данных

1. На новом сайте откройте «Обновление данных».
2. Выберите раздел, Excel/JSON или PDF. Для PDF выберите ДЭУ. Для тягачей выберите лист.
3. Проверьте состав и скачайте ZIP update_...zip.
4. В GitHub откройте папку updates и загрузите ZIP без распаковки. Если папки нет, создайте updates/.gitkeep через Add file → Create new file.
5. Commit changes запускает публикацию. После зеленого выполнения Actions обновите сайт. Архивы обновлений сохраняйте: они применяются последовательно по имени, от старых к новым.

Файлы на устройстве не сохраняются автоматически. Если закрыть страницу до скачивания ZIP, подготовку придется повторить. Обновление становится общим только после публикации в GitHub. Прямое сохранение на сервер и прежняя серверная история версий заменены файлами и историей GitHub. Контакты можно править в Excel/JSON и публиковать тем же способом.

Google My Maps остается внешним сервисом. Обновление таблицы тягачей не изменяет встроенную Google-карту автоматически.

## Перенос схем со старого сайта

Откройте /export на действующем сайте, войдите в свою учетную запись, скачайте все части. В новой версии выберите «Обновление данных → Перенос схем», добавьте все части, затем скачайте пакет обновления и загрузите его в updates репозитория. Встроенные схемы останутся в списке.

## Разработка

В SOURCE находится исходный код. npm ci, npm run check, npm run build. Результат — docs. Файлы public/data/*.json содержат опубликованный титул, контакты, тягачи и список схем. public/cleaning-schemes содержит исходные PDF; PDF.js поставляется локально, без CDN.

В папке SOURCE зависимости node_modules отсутствуют. Ничего из действующего Cloudflare-сайта или его настроек этот пакет не заменяет.
